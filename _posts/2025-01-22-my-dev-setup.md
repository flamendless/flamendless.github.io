To get things straight and out of the way I would like to apologize on behalf of the Linux community...

Yes, I am using Windows (forced due to company policy) as my OS but managing and compromising with WSL for the whole development workflow.

I will make a separate post on how WSL, especially with [tmux](https://github.com/tmux/tmux), makes developing on Windows tolerable.

Linux-y:
1. [WSL2](https://learn.microsoft.com/en-us/windows/wsl/install)
2. Terminal - [WezTerm](https://wezfurlong.org/wezterm/index.html)
3. Code editor - [neovim](https://neovim.io)
4. Source control management - [git](https://git-scm.com)
5. Shell - [zsh](https://www.zsh.org)
6. Multiplexer - [tmux](https://github.com/tmux/tmux)

Windows:
7. Note Taking - [Obsidian](https://obsidian.md)
8. File explorer - [Spacedrive](https://www.spacedrive.com)
9. Pomodoro timer - [Focus 10](https://apps.microsoft.com/detail/9nblggh5g2xh?hl=en-us&gl=US)
10. Password manager - [bitwarden](https://bitwarden.com)
11. Web browser - [Vivaldi](https://vivaldi.com)
12. API client - [Bruno](https://www.usebruno.com)
13. SQL client - [DBeaver](https://dbeaver.io)

I like the fact that whenever I get the chance to go full Linux again, I won't have problem with the Windows section since most of them are cross-platform and are not core parts to my dev setup.

For hardware, I am not that particular with it except for the keyboard. I am using the [Kinesis Freestyle 2](https://kinesis-ergo.com/keyboards/freestyle2-keyboard/) with V3 Tenting and a wood for wrists rest.

I used Arch BTW.
